# 微積分 PK

用選擇題練習大一微積分的網頁小遊戲。可以自己練，也可以和朋友即時對戰或互相挑戰，系統會記下錯題並找出最常錯的觀念。

線上版：<https://jack060719.github.io/calculus-visual/>

## 主要功能

- **單人練習**：六個主題（極限與連續、導數、導數應用、積分、積分技巧、級數與泰勒），另外有「綜合」交錯練習；難度分初級、中級、高級、混合。一局 8 題，每題限時 20 秒。
- **PK 對戰**：建立 4 位數房號，和朋友一對一即時對戰同一組題目。
- **挑戰連結**：打完一局可以發起挑戰，用 6 位數挑戰碼或連結讓朋友挑戰同一組題目。
- **排行榜**：每個挑戰各有自己的排行榜。
- **錯題本**：答錯的題目自動收進錯題本，可以重練；同一題在重練中連續答對 2 次就算「已掌握」。
- **學習診斷**：能力雷達圖（各主題答對率）、已作答題數、連續練習天數、最近 7 天，以及最常錯的觀念。

練習紀錄、錯題本都存在瀏覽器裡（localStorage），不需要註冊。PK 對戰和挑戰排行榜要連線（使用 Supabase）。

## 在本機執行

不需要安裝套件或建置，用任何靜態網頁伺服器開啟專案資料夾即可，例如：

```sh
python -m http.server 8000
```

再用瀏覽器開 <http://localhost:8000>。

## 檢查題庫

需要 Node.js：

```sh
node tools/verify.js
```

會驗證 300 題的答案與觀念標籤。
